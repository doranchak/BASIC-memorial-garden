# BASIC-memorial-garden
A place to put old BASIC programs I made or collected decades ago.  Some of them with ports for modern viewing.
  
## Mine

  * [Spiral 1](https://doranchak.github.io/BASIC-memorial-garden/spiral-plots/spiral1/spiral1.html) (June 1996) - A BASIC program that wrote out a DOS executable for displaying randomly generated fractal landscapes.

## Others

  * [Fracland](https://doranchak.github.io/BASIC-memorial-garden/fractal-landscape/FRACLAND.html) (1987) - Gradually draws a simple colorful spiral.
